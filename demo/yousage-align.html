3. 精力表焊上副屏

这是 YoUsage 的 L0，不是 Aindle。一上 HU%、休息按钮和复核催办，书桌就变成第二块人表。

第一刀就这三件事

  1. 采集补上真正的 wait：未闭合的权限 / 提问。现有 WAIT 徽章和 5 分钟刷新会自己变真。
  2. 主机条和本页改成 等你 N · 人手 M · 后台 K。同项目 3 个 SubAgent 不得把「人手」加成 4。
  3. 标题顺序：custom title / thread name / 目录名。禁止再拿 user 正文第一句当大字。

工作卡上的「目的 / 留下了什么 / 需要你」是 YoUsage 自己都还没验收的实验，本 Demo 中页也没有画它。第二刀最多先把「等你」和「可能可查看」两句文案分开。
