Desk-side board

让 AI 忙碌，
让你从容。

把分散在不同机器上的 AI 额度、用量和任务，收在一块安静的屏幕里。抬眼掌握进展，安心回到手边的事。

A private, read-only board for AI quotas and tasks. Self-hosted. Mock data on this page.

开源 · 自托管 · 为电子墨水屏而生

01 · On one screen

三件事，写在一块屏上

额度一目了然

各台机器、各份订阅还剩多少，一块屏上看清，不必来回切换工具。

进度心中有数

进行中的、待你确认的、在后台跑的，抬眼就知道现在该不该打断手头的事。

读书照常继续

锁屏上看看板；解锁之后，书架和翻页还在。看板不代替阅读。

02 · On the lock screen

屏上长这样

限额还剩多少，哪些在进行中、待确认或后台跑，刚结束的也写在下面。图里是示例数据，不是某台真机。

同一块看板也可以按小屏 Oasis 或大屏 Scribe 来看：先开 Hub 的 monitor 页，或直接打开在线示例。

03 · On a Kindle

也可以放在 Kindle 锁屏上

Kindle Oasis 1 可以把这块看板当作锁屏。这条路需要越狱。解锁之后，还是原来的阅读器。

图中和在线示例都是示例数据。真实额度来自你自己机器上的 agent；Hub 只跑在你的私网里。安装与原理见 GitHub README。

04 · Start

四条命令就能看见

  1. 克隆

    需要 Node.js 20 或更高。请 clone 仓库：包没有发到 npm。

    git clone https://github.com/Octo-o-o-o/aindle.git
cd aindle
npm install

  2. 启动 Hub

    默认带一份示例数据，避免空屏。第一次启动若尚未编译，会先编包装（几秒钟）。打开下面两个地址就能对照 README 里的图。不需要数据库或其它本机服务。

    npm run hub
# http://127.0.0.1:8787/monitor.html
# http://127.0.0.1:8787/eink.html?page=local

  3. 看自己的机器

    真实额度从这里来。只开 Hub 的话，屏幕上会一直是示例数据。在同一个 clone里另开终端；npx aindle 用的是仓库本地命令，不是 npm 全球包。编辑 registry 时只留你已登录的工具。

    npx aindle init --local
# 编辑 ./config/registry.yaml，只留你在用的工具
npx aindle agent --loop 60

可选：把 kindle/oasis1/ 拷到已越狱的 Oasis 1，改 hub.env 里的局域网地址，不要写 127.0.0.1。锁屏 PNG 需要 Hub 那台机器上的 Chrome / Chromium；只看网页看板不必装。锁屏看图，解锁读书。给编程 agent 的短说明在仓库 AGENTS.md 与 /llms.txt。
