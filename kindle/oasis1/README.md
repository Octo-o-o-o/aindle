# Kindle Oasis 1 · Aindle

默认 **锁屏才是 Monitor**。解锁后还是普通 Kindle：书桌、书库、翻页读书。不必再为了看书去停循环。

| 你想做的事 | 用什么 |
|---|---|
| 开着监控，平时照常看书 | KUAL → 开锁屏监控（本机） |
| 看监控 | 按电源键锁屏，或等屏保 |
| 立刻再拉一帧 | 立即刷新（锁屏中才会画到屏幕上） |
| 锁屏切本机 / 任务 / 中转 | 锁屏时按翻页键，或菜单里的锁屏翻页 |
| 点按钮、看详情 | 用网页操作 |
| 彻底关掉监控 | 关闭锁屏监控 |
| 插线拷文件 | Finder 推出后再开监控（U 盘模式循环是停的） |

## 必须知道的几条

1. **解锁不再盖桌面。** 循环在后台拉图，只在屏保上 `fbink`。看书、搜书、翻页都走 Kindle 自己。
2. **看监控 = 锁屏。** 电源键或设置里把屏保调短。合上皮套也是锁屏。
3. **翻页键只在锁屏时切 Aindle 页。** 读书时翻页还是翻书。
4. **U 盘和循环互斥。** 插线 = 只拷文件。推出、回桌面、连 Wi-Fi，再从 KUAL 开锁屏监控。
5. **不要用 127.0.0.1。** 先把 `hub.env.example` 复制成 `hub.env`（循环只读这个文件），再把示例 `http://192.168.1.2:8787` 改成 Hub 的真实局域网地址。端口默认与 Hub 一样是 **8787**，只改 IP，不要改成旧文档里的 `8790`。只改 example、不复制成 `hub.env`，设备仍会打示例地址。
6. **USBNetwork 没装。** 日常靠 Wi-Fi。USBNetwork 只为了 Mac SSH 调试。
7. **锁屏默认 10 分钟一刷。** 有进行中任务时 5 分钟。解锁不拉图。闹钟只在 `readyToSuspend` 里用 `lipc-set-prop -i … rtcWakeup` 设置；休眠前关掉 Wi-Fi，醒来再开。Oasis 进休眠时 `isScreenSaver` 常会先掉成 0，不能据此清 RTC。假解锁会再确认几秒；`loop.log` 里应出现 `rtcWakeup`、`wakeupFromSuspend`、第二次 `painted`。锁屏时一直开着无线，休眠后经常变成「标志位还是开、实际没网」。机上旧的 `hub.env` 若仍写着 `LOCK_HOLD_WIFI=1`，休眠前还是会关无线；想和现在默认一致，把那一行改成 `0` 或删掉。若还留着 `LOCK_HEARTBEAT_SEC=90`，闹钟会被截成 90 秒，可改成 `600` 或删掉。立刻看新数用「立即刷新」。改完脚本必须重新拷进 Kindle，并从 KUAL 关一次、开一次监控。
